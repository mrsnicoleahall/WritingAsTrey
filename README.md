# WritingAsTrey

Trey Plescher's writing portfolio — a dark, dramatic single-page timeline of his written work.

## Editing the text

All of the words on the site live in **`content.md`**. Open it, edit the text under any `Key:` or `Body:` / `Blurb:` field, save, and push — no HTML or CSS knowledge needed.

- Each `# Section` block (Hero, Chapter 01–05, Volume, Colophon) holds that section's copy.
- The `# Timeline` section holds one `## Entry` block per written work — `Title`, `Date`, `Link`, `Blurb`, and an optional `Easter-Egg` line. Add a new `## Entry` block to add a new work to the timeline. Add `Undated: true` to an entry that doesn't have a finish date yet.

## How it deploys

Every push to `main` runs [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml), which:

1. Runs `node build.js` — reads `content.md` + `template.html` and writes the finished site to `dist/`.
2. FTPs `dist/` to the live server, using the `FTP_SERVER`, `FTP_USERNAME`, and `FTP_PASSWORD` secrets already configured on this repo.

If the site needs to land in a subfolder on the host (e.g. `public_html/`), update `server-dir` in the workflow file.

## Building locally

```
node build.js
```

Outputs to `dist/index.html` (+ `dist/photos/`). No `npm install` required — the build script has no dependencies.

## Project structure

```
content.md     — all editable text + the timeline entries
template.html  — page structure, styling, and {{placeholders}}
build.js       — stitches content.md into template.html
photos/        — source images
dist/          — build output (not committed; regenerated by the Action)
```
